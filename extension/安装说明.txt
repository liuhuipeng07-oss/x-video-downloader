X 视频与 MP3 下载插件 0.2.3

1. 用 Chrome 打开 chrome://extensions
2. 开启右上角「开发者模式」
3. 点击「加载已解压的扩展程序」
4. 选择本文件所在的文件夹（里面应直接包含 manifest.json）
5. 刷新 X 页面

帖子旁：
「下载视频」和「下载 MP3」打开选择菜单，可先查看文件大小。
菜单中的 MP4 保存最高可用清晰度视频，MP3 在本机提取音轨并转换为 128 kbps。
MP3 成品大小按时长估算，读取源视频所用流量可能更大。
「⌄」选择清晰度或帖子里的其他视频。

打开 X 帖子后点击工具栏插件，会自动获取当前帖子的视频；也可以复制其他 X 链接，点击「粘贴地址」，再点「获取视频」。
关闭弹窗后 MP3 转换会继续，请保持 Chrome 运行。
转换进度和取消按钮在插件弹窗中。
保存到 Chrome 下载目录的 X_Videos 文件夹。

需要 Chrome 116 或更新版本。
没有音轨的视频不能导出 MP3；首版不支持 Spaces 直播、DRM 或仅有 HLS 的帖子。
无需安装 FFmpeg / Node。转换引擎已包含在插件内。

插件为开发测试版本；如遇问题请反馈具体帖子链接及错误信息。
详细说明和源码见项目的 README.md。
