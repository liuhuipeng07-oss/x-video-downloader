# X 视频与 MP3 下载插件

Chrome 插件，支持在 X 帖子中保存 MP4 视频、提取 MP3 音轨，下载前查看文件大小。

## 安装

1. 在 [Releases](../../releases/latest) 下载 ZIP，并解压到固定目录。
2. 在 Chrome 地址栏打开 `chrome://extensions`，开启「开发者模式」。
3. 点击「加载已解压的扩展程序」，选择包含 `manifest.json` 的解压目录。
4. 刷新已打开的 X 页面。建议在 Chrome 工具栏的拼图菜单中固定插件。

也可下载仓库源码，在第 3 步选择其中的 `extension` 文件夹。保留解压目录，Chrome 需要持续读取其中的文件。需要 Chrome 116 或更新版本。

## 使用

- 打开 X 视频帖子，点击帖子旁的下载按钮，查看大小并选择 MP4 或 MP3；多段视频可分别选择。
- 也可打开工具栏弹窗。当前帖子会自动识别；其他帖子可复制链接，点击「粘贴地址」和「获取视频」。
- MP4 大小来自服务器信息；MP3 大小根据时长和 128 kbps 码率估算。MP3 在本机转换，保持 Chrome 运行即可；可在弹窗查看进度或取消。
- 文件保存到 Chrome 下载目录的 `X_Videos` 文件夹。

## 范围和权限

目前面向 X/Twitter 的普通视频帖子。直播、DRM、仅提供 HLS 的视频暂不支持。访问受限内容需要在浏览器中具有相应访问权限；网页结构或接口变化可能导致功能失效。

插件访问 X 页面、X 嵌入接口和 X 视频 CDN，读取页面加载的视频信息。`clipboardRead` 仅在点击粘贴按钮时读取剪贴板；`downloads` 用于保存和跟踪下载，`storage` 用于会话状态，`offscreen` 用于后台音频转换。MP3 转换在本机进行。

## 开发与验证

安装插件无需 Node 或 FFmpeg。开发环境需要 Node.js；测试 MP3 解码还需要 FFmpeg / ffprobe。运行 `npm ci`、`npm run build`、`npm test`。示例测试数据为合成数据。

已完成本地自动化和真实媒体文件验证；Chrome 页面布局、不同账号及更长音频的兼容性仍需要实际测试。使用者反馈曾成功完成一次下载，具体格式未记录，不代表所有流程均已验证。

本项目使用 Mediabunny（MPL-2.0）及 LAME（LGPL）；来源与许可见 `extension/vendor`。`build.mjs` 记录了编码器工作线程的打包方式。
